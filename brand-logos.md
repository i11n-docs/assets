## Favicon

[Download](https://docs.i11n.io/assets/img/favicon.zip)

### Instructions
1. Download the `.zip` file [https://docs.i11n.io/assets/img/favicon.zip](https://docs.i11n.io/assets/img/favicon.zip)
2. Extract the `.zip` to the web site root.
3. Insert the code below.
  ```
  <link rel="icon" type="image/png" href="/favicon-96x96.png" sizes="96x96" />
  <link rel="icon" type="image/svg+xml" href="/favicon.svg" />
  <link rel="shortcut icon" href="/favicon.ico" />
  <link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png" />
  <meta name="apple-mobile-web-app-title" content="i11n" />
  <link rel="manifest" href="/site.webmanifest" />
  ```
4. Adjust the `meta` element's `content` property (line 5) to the site, or app, name.
5. In the `site.manifest` file, update the `name` and `short_name` properties to the site, or app, name and short name.
  - You may also wish to update the `theme_color` and `background_color` properties to the sites colors.
